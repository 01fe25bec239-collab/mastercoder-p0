# A2 Web and UX

## Charter

Own Next.js/React/TypeScript information architecture, review/evidence/coverage views, local-first disclosure, accessible state language, patch diff/manifest presentation, and direct WebAuthn ceremony.

## Required properties

UI is a projection, not authority. Every non-pass/partial/stale/unsupported/unknown state is explicit. Approval renders the complete exact tuple and invalidates on change. Large-diff truncation cannot conceal unreviewed approval. Security does not rely only on color.

## Dependencies and gates

ADRs 004, 005, 011, 012, 013. P0-06/P0-09 plus accessibility validation. Implementation status: NOT_AUTHORIZED.

## Review handoff

Deliver exact-state screenshots/flows, keyboard/screen-reader tests, stale transition behavior, challenge origin/RP integration, full-diff alternative, source-transfer disclosure, and no-authority server action review.
