# V2 to V2.1 changelog

The original ZIP and extracted V2 remain byte-for-byte preserved. This is a separate version of the same architecture, with original sound decisions retained and dependent documents updated directly.

| Area | Bounded semantic change |
|---|---|
| Git publication | Independent gateway enforces five exact create operations; planner credential-free; no false claim that stolen token itself is create-only |
| Check currentness | Explicit projection identity, serialized per-call writes, confirmed withdrawal, normal staged activation and emergency unsafe interval/provider freeze |
| Approval | Separate canonical display origin, exact custody, fresh purpose-bound UV and independent constructible registration/recovery lifecycle |
| Gate truth | Protected producer/DB writer matrix; expected mandatory unit manifest and zero-finding completion receipts; oracle validity separate from causal reproduction |
| Distributed effects | Actual expiry after lock; per-call intent/state and two-copy durable witness before send; no 404-based absence; full journal restore enumeration |
| Recovery | All restored authorizations denied pending independent fresh bootstrap; infrastructure RTO target does not promise privileged authority recovery time |
| Contracts | Complete ordered schemas, explicit options/widths/enums/domains, strict revision negotiation, positive/rejection vector specification and glossary |
| Product/operation | Pin exact patch bytes; bounded dependency acquisition; scoped manual decisions never mint PASS; honest individual/C3 profiles |
| Delivery | FAST deterministic work independent of models;55 atomic P0 contracts across ten original groups; diagrams through actual trusted ingress |
